# 要件定義書: プライバシーポリシー実装

## 1. 背景・目的

BrainGame は Google Play に公開するための Android アプリである。
Google AdMob を使用しているため、Google Play Developer Program Policy により
以下が**必須要件**となっている。

- アプリ内にプライバシーポリシーページを公開し、アクセスできること
- Play Console「アプリのコンテンツ > プライバシーポリシー」に URL を登録すること
- ユーザーが初回起動時にプライバシーポリシーに同意する UI を設けること（「認識しやすい開示と同意」要件）
- 日本の個人情報保護法（2024年改正施行規則）に準拠すること

本プロジェクトでは、上記要件を満たすための最小実装セットを定義する。

## 3. 機能要件

### FR-1: プライバシーポリシーページ（`/privacy-policy`）の新規作成

| ID | 要件 |
|---|---|
| FR-1-1 | URL `/privacy-policy` で全世界からアクセス可能なページを公開する |
| FR-1-2 | ページタイトルは「プライバシーポリシー」と明示する |
| FR-1-3 | 日本語で記載する |
| FR-1-4 | 以下のセクションを全て含む（詳細は後述） |
| FR-1-5 | 既存のダークテーマ（背景 `#0f0f1a`）に合ったスタイルを適用する |
| FR-1-6 | ページ上部に「← ホームへ戻る」リンクを配置する |

**FR-1-4 必須セクション一覧**

1. はじめに（アプリ名・開発者・最終更新日）
2. 収集する情報（ユーザー入力情報・AdMob 自動収集情報）
3. 情報の利用目的
4. 第三者へのデータ提供（Google AdMob / Turso / Vercel）
5. 外国への個人情報の提供（米国）
6. 広告について（AdMob パーソナライズ・オプトアウト）
7. ユーザーの権利（開示・削除リクエスト）
8. データの保存期間
9. データの安全管理
10. 子供のプライバシー（13歳未満対象外）
11. プライバシーポリシーの変更
12. お問い合わせ

### FR-2: タイトル画面（`/`）フッターへのリンク追加

| ID | 要件 |
|---|---|
| FR-2-1 | `app/page.tsx` の画面下部に「プライバシーポリシー」テキストリンクを追加する |
| FR-2-2 | リンク先は `/privacy-policy` |
| FR-2-3 | Next.js の `<Link>` コンポーネントを使用する |
| FR-2-4 | 既存のフッターテキスト（「スコアはクラウドに保存されます」）と同行または直下に配置し、小さいサイズ・目立ちすぎないスタイルとする |

---

### FR-3: `NicknameModal` への同意チェックボックス追加

| ID | 要件 |
|---|---|
| FR-3-1 | ニックネーム入力フォームの下部（ボタン群の直上）に「プライバシーポリシーに同意する」チェックボックスを追加する |
| FR-3-2 | 「プライバシーポリシー」というテキスト部分は `/privacy-policy` へのリンク（新しいタブで開く） |
| FR-3-3 | チェックが入っていない場合、「はじめる！」ボタン（`mode === "setup"` 時）を無効化（`disabled`）する |
| FR-3-4 | `mode === "change"` 時はチェックボックスを非表示とする（既に同意済みのため） |
| FR-3-5 | チェックボックスの初期状態は未チェック（`false`） |

## 4. 非機能要件

| ID | 要件 |
|---|---|
| NFR-1 | プライバシーポリシーページは静的レンダリング（SSG）で配信する。動的なデータフェッチは不要 |
| NFR-2 | ページは SEO 対策として `<title>` と `<meta description>` を適切に設定する |
| NFR-3 | モバイル端末（幅320px〜）でレイアウトが崩れないこと |
| NFR-4 | 既存の Tailwind CSS / globals.css のスタイルユーティリティ（`.card`, `.btn-primary` 等）を活用する |
| NFR-5 | 新規 npm パッケージの追加は不要（既存の Next.js / React / Tailwind で実装） |

---

## 5. 対象外スコープ

- Play Console へのプライバシーポリシー URL 登録作業（手動作業、本実装後に別途実施）
- アカウント削除 UI の実装（メールによる削除リクエスト受付のみで代替）
- AdMob テストモードから本番 ID への切り替え（別タスク）
- TCF v2.3 / GDPR 対応の同意管理プラットフォーム（CMP）導入（現時点は将来課題）
- 多言語対応（英語等）
