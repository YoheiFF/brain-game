# 要件定義: 図形記憶ゲーム グリッド 4×4 → 5×5 変更

## 1. ユーザー要件

### 1.1 背景・目的

図形記憶（pattern）ゲームは 4×4（16 マス）グリッドで実装されており、後半レベルで「光るマスが全体の大多数を占める」という難易度逆転問題が発生している。

- 4×4 のとき lvl=13 以上で 15 マスが光る → 残り 1 マスだけ暗い状態になり「消えているマスを探す」ゲームに変質する
- 5×5（25 マス）にすることで上限 24 マスまで余裕が生まれ、後半も「光っているマスを覚える」難易度が右肩上がりに維持される

### 1.2 ユーザーが本当に必要としているもの

| ニーズ | 解決手段 |
|--------|---------|
| 後半レベルで難易度が単調増加すること | GRID を 5 に変更し、最大表示マス数を 24/25 に引き上げる |
| 変更後も画面が崩れないこと | セルサイズを 56px → 48px に縮小して 5 列が max-w-sm 内に収まるようにする |
| 既存スコア・ランキングが壊れないこと | lib 層は GRID に非依存なので変更なしで継続動作する |

---

## 2. システム要件

### 2.1 機能要件

| ID | 要件 | 優先度 |
|----|------|--------|
| FR-01 | グリッドは 5×5（25 マス）で描画される | 必須 |
| FR-02 | パターン生成時の最大マス数は 24（TOTAL-1）に制限される | 必須 |
| FR-03 | グリッド列数は GRID 定数から動的に決まる（`repeat(${GRID}, 1fr)`）| 必須 |
| FR-04 | 各セルのサイズは `w-12 h-12`（48px × 48px）である | 必須 |
| FR-05 | スコア保存・個人ベスト取得・ランキング計算は変更前と同一の動作を維持する | 必須 |
| FR-06 | デイリープレイ管理（1日3回制限）は変更前と同一の動作を維持する | 必須 |
| FR-07 | ゲーム終了時の ResultModal でベンチマーク比較が正常に表示される | 必須 |

### 2.2 変更対象

| 対象 | 変更内容 |
|------|---------|
| `app/games/pattern/page.tsx` | `GRID = 4` → `GRID = 5`、セルクラス `w-14 h-14` → `w-12 h-12` |
| その他のファイル | 変更なし（GRID に非依存） |

---

## 3. 非機能要件

| ID | 区分 | 要件 |
|----|------|------|
| NFR-01 | レイアウト | 最小幅 320px のモバイル端末で 5 列グリッドが横スクロールなしで表示される |
| NFR-02 | レイアウト | max-w-sm（384px）内で 5 列 × 48px + gap-2 × 4 = 248px が収まる（padding 考慮で余裕あり）|
| NFR-03 | 型安全性 | `npx tsc --noEmit` でコンパイルエラーが発生しない |
| NFR-04 | 後方互換性 | localStorage の既存データ構造（`braingame_scores`、`braingame_rankings`、`braingame_daily`）を破壊しない |
| NFR-05 | パフォーマンス | グリッドセル数が 16 → 25 に増加してもレンダリング遅延は体感できない（< 16ms/frame 維持）|
| NFR-06 | ベンチマーク整合性 | 現在のベンチマーク値（20代平均 18点）は 4×4 時代の実績値であり、5×5 化後は将来的に再調整が必要（現バージョンでは変更しない）|

---

## 4. 受け入れ条件

以下の条件がすべて満たされた場合に本変更を完了とみなす。

| # | 条件 | 検証方法 |
|---|------|---------|
| AC-01 | `app/games/pattern/page.tsx` の `GRID` 定数が `5` である | コードレビュー |
| AC-02 | セルの Tailwind クラスが `w-12 h-12` である | コードレビュー |
| AC-03 | `npx tsc --noEmit` がエラーなしで完了する | 静的型チェック実行 |
| AC-04 | ゲームプレイ時にグリッドが 5×5（25 マス）で表示される | ブラウザ目視確認 |
| AC-05 | モバイル幅（375px 相当）でグリッドが横スクロールなしで表示される | DevTools レスポンシブ確認 |
| AC-06 | ゲーム終了後にスコアが localStorage に保存され、リロード後もベストスコアが表示される | ブラウザ動作確認 |
| AC-07 | 既存の `getTotalPlayCount()` 等のスコア集計関数がグリッド変更後も正常に動作する | コードレビュー（lib 層の GRID 非依存性を確認）|
