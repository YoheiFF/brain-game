# 依頼: モバイルアプリリリースに向けたDB接続・キャッシュ・セキュリティ監査

## 依頼内容
BrainGame をモバイルアプリ（Capacitor + Android）としてリリース検討中。
Turso DB 統合後の DB 接続・キャッシュ・セキュリティ面で問題がないか確認し、必要であれば修正する。

## 確認観点
- DB 接続（認証情報の露出リスク、接続エラー時の挙動）
- キャッシュ（localStorage との整合性、オフライン時の挙動）
- セキュリティ（API エンドポイントの認可、入力バリデーション、XSS/インジェクション）
- モバイル固有の問題（Capacitor 環境での fetch、CORS、環境変数）
