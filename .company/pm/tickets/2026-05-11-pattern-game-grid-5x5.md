# 図形記憶ゲーム: グリッドを4×4→5×5に変更

## 内容
図形記憶（pattern）ゲームのグリッドを 4×4（16マス）から 5×5（25マス）に変更。
後半レベルで光るマスが全体の多数を占め「逆に簡単」になる問題を解消する。

## 背景・理由
- 4×4 では最大15マスが光る → 全16マス中15マスは視覚的に「消えているマスを覚える」だけになり難易度が逆転する
- 5×5（25マス）にすることで上限24マスまで余裕が生まれ、後半も難易度が右肩上がりになる

## 設計参照
- 関連ファイル: `app/games/pattern/page.tsx`

## 変更内容

### app/games/pattern/page.tsx
```typescript
// 変更前
const GRID = 4;  // 4×4 = 16マス

// 変更後
const GRID = 5;  // 5×5 = 25マス
```

```typescript
// セルサイズ（5列で画面に収まるよう縮小）
// 変更前: w-14 h-14（56px）
// 変更後: w-12 h-12（48px）
```

## レベル別マス数（変更後）

| レベル | 表示マス数 | 全体の割合 |
|--------|-----------|-----------|
| 1 | 3マス | 12% |
| 5 | 7マス | 28% |
| 10 | 12マス | 48% |
| 15 | 17マス | 68% |
| 22以上 | 24マス（上限） | 96% |
